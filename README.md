# Yandex Maps Leads

**От поиска на карте — к списку потенциальных клиентов.**

Скилл для Codex и Python-парсер для сбора организаций из Яндекс Карт по городу и категории. Собирает контакты, рейтинги и ссылки на карточки в CSV. Помогает составлять списки компаний, у которых в карточке не указан отдельный сайт.

## Возможности

- Поиск по городу, региону и категории бизнеса.
- Обход территории сеткой для более широкого покрытия.
- Название, адрес, телефон, сайт, соцсети, часы работы, рейтинг и число отзывов.
- Выгрузка CSV в UTF-8 с BOM для открытия в Excel.
- Ограничение размера выборки и удаление повторов по ID карточки.
- По запросу — поиск email на сайтах организаций.
- Готовые инструкции для работы через Codex.

## Установка в Codex

Передайте Codex ссылку на этот репозиторий и попросите установить скилл из корня репозитория:

> Установи скилл yandex-maps-leads из https://github.com/Ziptor/yandex-maps-leads — файл SKILL.md находится в корне. Сохрани всю папку вместе с parser.

Для ручной установки склонируйте репозиторий в каталог пользовательских скиллов:

```sh
git clone https://github.com/Ziptor/yandex-maps-leads.git ~/.agents/skills/yandex-maps-leads
```

В Windows соответствующий каталог — `%USERPROFILE%\.agents\skills\yandex-maps-leads`. После установки начните новый чат Codex, если скилл не появился в текущем.

## Быстрый старт

Требуются Git, uv и Python. В репозитории закреплён Python 3.12; проект заявляет поддержку Python 3.10+.

```sh
git clone https://github.com/Ziptor/yandex-maps-leads.git
cd yandex-maps-leads/parser
uv sync --locked
uv run playwright install chromium
uv run yamaps_parser.py "Казань" "барбершоп" --no-grid --limit 20 --output leads.csv
```

### Более широкий поиск

По умолчанию парсер обходит территорию сеткой:

```sh
uv run yamaps_parser.py "Санкт-Петербург" "автосервис" --limit 100 --output leads.csv
```

### Поиск email

```sh
uv run yamaps_parser.py "Казань" "кофейни" --no-grid --limit 20 --emails --output leads.csv
```

Поиск email выполняется отдельным шагом и увеличивает время работы. Без `--emails` он выключен.

## Примеры запросов к Codex

- «Найди 30 барбершопов в Казани и сохрани контакты в CSV».
- «Собери автосервисы в Самаре, у которых не указан отдельный сайт».
- «Найди кофейни в Перми, сохрани телефоны, рейтинги и ссылки на карточки».

Для списка без отдельного сайта скилл предлагает отобрать пустое поле `site` и ссылки только на соцсети, мессенджеры или каталоги. Это работа Codex с результатами выгрузки, отдельного CLI-флага для фильтра нет.

## Параметры

| Параметр | Назначение |
|---|---|
| `place` | Город или регион |
| `query` | Категория или поисковый запрос |
| `--limit N` | Максимальное число организаций |
| `--output PATH` | Путь к CSV |
| `--no-grid` | Один поиск без обхода территории сеткой |
| `--bbox MIN_LON,MIN_LAT,MAX_LON,MAX_LAT` | Явные границы поиска |
| `--cell LON,LAT` | Размер ячейки сетки |
| `--split-threshold N` | Порог дробления ячейки |
| `--headful` | Показать браузер |
| `--url URL` | Использовать готовую ссылку поиска; позиционные аргументы всё равно обязательны |
| `--emails` | Искать email на сайтах организаций |
| `--email-delay SECONDS` | Пауза между запросами к сайтам |

Полная справка: `uv run yamaps_parser.py --help`.

## Поля CSV

`id, name, category, address, lon, lat, phone, site, social, hours, rating, reviews, url, email`

## Ограничения

Разметка Яндекс Карт может меняться; капча, ограничения сервиса или изменения выдачи могут прерывать сбор. Полнота результатов не гарантируется. Отсутствие сайта в карточке не доказывает, что у компании нет сайта: для точной проверки используйте название, город и телефон.
